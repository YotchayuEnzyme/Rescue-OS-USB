2. Setup & Configuration (การตั้งค่าระบบ)
(Note: ส่วนนี้สำคัญมาก หากระหว่างการพัฒนาเกิดข้อผิดพลาดหรือระบบพัง สามารถใช้บันทึกส่วนนี้ในการรีเซ็ต (Reset) และเริ่มต้นสร้างสภาพแวดล้อมใหม่ทั้งหมดได้อย่างรวดเร็ว)

2.1 สเปก VM ที่ตั้งค่าไว้ (VirtualBox Settings)
ก่อนกด Start เครื่องทุกครั้ง (โดยเฉพาะเมื่อย้ายที่เก็บไฟล์ หรือสร้าง VM ใหม่) ต้องตรวจสอบการตั้งค่าฮาร์ดแวร์จำลองดังนี้:

Storage: ชี้ไฟล์ Optical Drive ไปที่ไฟล์ ISO ของ Alpine Linux (รันแบบ Live CD)

Display (สำคัญมาก ป้องกันหน้าจอพัง/จอดำ):

Video Memory: ปรับเป็น 128 MB

Graphics Controller: เลือก VBoxSVGA เท่านั้น

Network (เปิดทางให้เชื่อมต่อรีโมต):

ไปที่ Adapter 1 > Advanced > Port Forwarding

สร้าง Rule ใหม่: กำหนด Host Port เป็น 2222 และ Guest Port เป็น 22

2.2 คำสั่งตั้งค่าพื้นฐานรอบที่ 1 (รันที่หน้าจอหน้าต่าง VM โดยตรง)
เมื่อบูตระบบเสร็จและขึ้น localhost login: ให้ล็อกอินด้วยผู้ใช้ root (ไม่ต้องใช้รหัสผ่าน) จากนั้นรันคำสั่งต่อไปนี้เพื่อเปิดระบบเน็ตเวิร์กและ SSH:

Bash
# 1. ตั้งรหัสผ่านให้ผู้ใช้ root (ต้องพิมพ์ 2 รอบ เพื่อความปลอดภัยตอนรีโมต)
passwd

# 2. ตั้งค่า DNS ไปที่ Cloudflare (1.1.1.1) เพื่อแก้ปัญหาโหลดแพ็กเกจไม่ผ่าน
echo "nameserver 1.1.1.1" > /etc/resolv.conf

# 3. ติดตั้งและเปิดใช้งานเซอร์วิส SSH
setup-sshd -c openssh

# 4. อนุญาตให้ user ระดับ root สามารถรีโมตผ่าน SSH ได้
echo "PermitRootLogin yes" >> /etc/ssh/sshd_config

# 5. รีสตาร์ตเซอร์วิส SSH เพื่อนำการตั้งค่าใหม่มาใช้งาน
rc-service sshd restart
2.3 แก้ไข Repositories และอัปเดตระบบ (รันผ่าน CMD ของ Windows)
เมื่อเซอร์วิส SSH ทำงานแล้ว ให้สลับมาเปิด Command Prompt (CMD) บนเครื่อง Windows และเชื่อมต่อด้วยคำสั่ง:
ssh -p 2222 root@127.0.0.1 (พิมพ์ yes และใส่รหัสผ่านที่ตั้งไว้)

เมื่อเชื่อมต่อสำเร็จ ให้ก๊อปปี้ชุดคำสั่งนี้ไปวางเพื่อเตรียมคลังแพ็กเกจให้พร้อมก่อนลง GUI:

Bash
# 1. ซิงก์เวลาของระบบให้ตรงกับปัจจุบัน (แก้ปัญหา SSL Certificate Error ตอนโหลดไฟล์)
chronyd -q 'server pool.ntp.org iburst'

# 2. ปลดล็อก (Uncomment) คลังแพ็กเกจย่อย "community" ในไฟล์ repositories
sed -i 's/^#\(.*\/community\)/\1/' /etc/apk/repositories

# 3. อัปเดตรายการแพ็กเกจทั้งหมดในระบบให้เป็นเวอร์ชันล่าสุด
apk update

# 4.เช็คไฟล์ใน drive ที่เห็น
lsblk -o NAME,SIZE,FSTYPE,LABEL,MOUNTPOINT
