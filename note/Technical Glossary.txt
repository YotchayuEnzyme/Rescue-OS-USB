## 2. คำศัพท์ที่ควรรู้และนิยามศัพท์ (Technical Glossary)

### หมวดสถาปัตยกรรมของ Alpine Linux (Core Architecture)

**1. Diskless Mode (Live RAM Mode)**

โหมดการทำงานที่ระบบปฏิบัติการจะถูกโหลดจากสื่อบันทึกข้อมูล (ISO/USB) ขึ้นไปรันบนหน่วยความจำชั่วคราว (RAM) 100% ทำให้ระบบทำงานได้รวดเร็ว และไม่แตะต้องหรือรบกวนข้อมูลบนฮาร์ดดิสก์ของเครื่องเป้าหมาย

**2. `apk` (Alpine Package Keeper)**

โปรแกรมจัดการแพ็กเกจ (Package Manager) ประจำตัวของ Alpine Linux ทำหน้าที่ดาวน์โหลด ติดตั้ง และอัปเดตซอฟต์แวร์ (เทียบเท่ากับ `apt` ใน Debian/Ubuntu)

**3. `lbu` (Alpine Local Backup)**

เครื่องมือเฉพาะของ Alpine สำหรับรวบรวมไฟล์การตั้งค่าและสคริปต์ที่แก้ไขบน RAM แล้วแพ็กบีบอัดเป็นไฟล์เดียว (`.apkovl.tar.gz`) ลงในแฟลชไดรฟ์ เพื่อโหลดกลับมาใช้งานต่อโดยอัตโนมัติเมื่อเปิดเครื่องครั้งถัดไป

**4. OpenRC**

ระบบจัดการเซอร์วิส (Init System) ของ Alpine Linux ใช้ควบคุมการเปิด-ปิดโปรแกรมเบื้องหลังผ่านคำสั่ง `rc-service` และ `rc-update` โดยเน้นความเบา รวดเร็ว และกินทรัพยากรต่ำ ต่างจาก `systemd` บนดิสโทรทั่วไป

---

### หมวดระบบแสดงผลและอุปกรณ์ (GUI & Hardware Integration)

**1. Xorg (X Window System / X11)**

โครงสร้างพื้นฐานในการแสดงผลกราฟิก ทำหน้าที่วาดกรอบหน้าต่าง จัดการระบบสี และรับค่าอินพุตจากการขยับเมาส์หรือการกดแป้นพิมพ์

**2. XFCE4 (Desktop Environment)**

ชุดสภาพแวดล้อมเดสก์ท็อปที่ทำงานอยู่บน Xorg ประกอบด้วยแถบพาเนล เมนูจัดการระบบ และหน้าต่างจัดการไฟล์ โดยออกแบบมาให้ใช้ทรัพยากรเครื่องน้อยมาก

**3. `udev` & `dbus`**

- **`udev`:** ระบบจัดการและตรวจจับอุปกรณ์ฮาร์ดแวร์แบบไดนามิก เช่น การเสียบเมาส์ คีย์บอร์ด หรือแฟลชไดรฟ์เข้าเครื่อง
- **`dbus` (Desktop Bus):** ตัวกลางส่งข้อความสื่อสารระหว่างโปรแกรมภายในหน้าจอเดสก์ท็อป เพื่อให้อินเทอร์เฟซและอุปกรณ์ทำงานสัมพันธ์กัน

---

### หมวดการจัดการดิสก์และกู้ข้อมูล (Storage & Data Recovery)

**1. Block Device (`/dev/sda`, `/dev/sdb`)**

ชื่ออ้างอิงอุปกรณ์จัดเก็บข้อมูลระดับฮาร์ดแวร์ในลินุกซ์ โดย `sda` หมายถึงดิสก์ลูกแรก และตัวเลขต่อท้าย เช่น `sda1` หมายถึงพาร์ทิชันที่ 1 ภายในดิสก์ลูกนั้น

**2. Mounting (การเมานต์ดิสก์)**

กระบวนการเชื่อมพาร์ทิชันของพื้นที่จัดเก็บข้อมูล (เช่น `/dev/sda1`) เข้ากับโครงสร้างโฟลเดอร์ในระบบ (เช่น `/mnt/sda1`) เพื่อให้ระบบสามารถเข้าถึง อ่าน หรือคัดลอกไฟล์ได้

**3. Read-Only Mount (`mount -o ro`)**

การเมานต์ดิสก์แบบอ่านข้อมูลได้อย่างเดียว ห้ามเขียนหรือแก้ไขไฟล์โดยเด็ดขาด เป็นมาตรฐานความปลอดภัยในงานกู้ข้อมูลและนิติวิทยาศาสตร์ดิจิทัล เพื่อป้องกันไม่ให้ระบบเขียนทับข้อมูลเดิมที่เสียหาย

**4. File System (ระบบไฟล์)**

โครงสร้างที่ใช้จัดเก็บและจัดการข้อมูลบนดิสก์ เช่น

- **NTFS:** ระบบไฟล์มาตรฐานของ Windows
- **FAT32 / exFAT:** ระบบไฟล์ที่นิยมใช้กับแฟลชไดรฟ์และอุปกรณ์จัดเก็บข้อมูลภายนอก
- **ext4:** ระบบไฟล์ที่นิยมใช้ในระบบปฏิบัติการลินุกซ์

---

### หมวดเครือข่ายและการจำลองระบบ (Networking & Virtualization)

**1. NAT & Port Forwarding**

การจำลองเครือข่ายให้เครื่องเสมือน (VM) ใช้อินเทอร์เน็ตร่วมกับเครื่องหลัก (Host Windows) และกำหนดเส้นทางพอร์ตเครือข่าย เช่น จาก Host Port `2222` ไปยัง Guest Port `22` ของ VM เพื่อให้เรียกใช้งานข้ามเครื่องได้

**2. SSH (Secure Shell)**

โปรโตคอลการสื่อสารระยะไกลเพื่อเข้าควบคุมระบบผ่านคอมมานด์ไลน์ โดยมีการเข้ารหัสข้อมูลระหว่างการส่งผ่านเครือข่าย

**3. `udhcpc`**

ไคลเอนต์ขนาดเล็ก (Micro DHCP Client) ที่ใช้ส่งคำขอรับหมายเลข IP Address จากระบบเครือข่ายหรือตัวจัดการของ VirtualBox โดยอัตโนมัติ

**4. DNS (`resolv.conf`)**

ระบบแปลงชื่อโดเมน เช่น ชื่อเซิร์ฟเวอร์คลังแพ็กเกจของ Alpine ให้เป็นหมายเลข IP Address เพื่อให้ระบบสามารถเชื่อมต่อและดาวน์โหลดไฟล์หรือแพ็กเกจผ่านเครือข่ายอินเทอร์เน็ตได้อย่างถูกต้อง
